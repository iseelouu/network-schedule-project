# network-schedule-project
# Сетевой график работ

## Описание проекта

Программа предназначена для построения и расчёта сетевого графика работ проекта с учётом зависимостей между работами и рабочего календаря.

С помощью программы можно определить последовательность выполнения работ, рассчитать сроки выполнения проекта и выявить критические пути.

## Основные возможности

- Создание проекта и добавление работ.
- Указание продолжительности работ в рабочих днях.
- Назначение исполнителей и статусов работ.
- Установка зависимостей между работами.
- Поддержка четырёх типов зависимостей:
    - `FINISH_TO_START` — окончание → начало.
    - `START_TO_START` — начало → начало.
    - `FINISH_TO_FINISH` — окончание → окончание.
    - `START_TO_FINISH` — начало → окончание.
- Учёт выходных дней и праздников.
- Расчёт раннего и позднего начала и окончания каждой работы.
- Расчёт временных резервов.
- Определение критического пути и общей продолжительности проекта.
- Обнаружение циклических зависимостей с выводом списка работ, образующих цикл.

## Используемые технологии

- Java 21
- Maven
- JUnit 5

## Структура проекта

- `network.schedule.model` — классы предметной области:
    - `Work` — работа.
    - `Project` — проект.
    - `Executor` — исполнитель.
    - `Dependency` — зависимость между работами.
    - `DependencyType` — тип зависимости.
    - `WorkCalendar` — рабочий календарь.
    - `StandardWorkCalendar` — стандартная реализация рабочего календаря.
    - `WorkSchedule` — рассчитанное расписание работы.
    - `ScheduleResult` — результат расчёта.
    - `WorkStatus` — статус работы.
    - `Main` — демонстрация работы программы.

- `network.schedule.service` — логика расчёта:
    - `ScheduleCalculator` — расчёт сетевого графика.
    - `CycleDependencyException` — исключение при обнаружении цикла.
    - `VisitState` — состояние посещения работы при обходе графа.

## Запуск программы

Для запуска демонстрации необходимо открыть проект в IntelliJ IDEA и запустить класс `Main`.

В демонстрации создаётся проект из 30 работ, задаются зависимости между ними и рассчитывается расписание.

## Результаты работы

Программа выводит для каждой работы:

- раннюю дату начала;
- раннюю дату окончания;
- позднюю дату начала;
- позднюю дату окончания;
- общий временной резерв.

Также выводятся общая продолжительность проекта и найденные критические пути.
